# Soares Autoclinic — Site demonstrativo

Site estático e responsivo para apresentação comercial da oficina **Soares Autoclinic**, Cabuçu, Nova Iguaçu (RJ). Contém HTML, CSS e JavaScript simples: não depende de instalação, compilação, Node.js ou serviços pagos.

## Abrir e testar
1. Descompacte o ZIP.
2. Abra `index.html` no navegador.
3. Se preferir servidor local: `python -m http.server 8000` e visite `http://localhost:8000`.

## Publicar no GitHub Pages
1. Crie um **novo repositório** no GitHub chamado `soares-autoclinic` (não use um repositório antigo de outro cliente).
2. Envie todos os arquivos e a pasta `assets/` à raiz desse repositório.
3. Em **Settings → Pages → Build and deployment**, selecione **Deploy from a branch** e **main / (root)**.
4. O endereço será semelhante a `https://SEU-USUARIO.github.io/soares-autoclinic/` depois da publicação.
5. Como é uma demonstração comercial, mantenha o aviso de site não oficial até obter aprovação da empresa. Se usar um repositório público, arquivos e informações ficam públicos.

- **Demonstração não oficial** para apresentação ao estabelecimento, não é um site publicado/autorizado pela empresa.
- A avaliação 5,0 (16 reviews) é uma informação fornecida para a proposta e pode mudar.
